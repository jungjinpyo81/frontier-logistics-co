# 하단 위치 지도 추가

푸터 바로 위(페이지 제일 하단)에 본사 위치를 보여주는 Google 지도 섹션을 추가합니다.

## 표시 내용
- 주소: 경기도 고양시 덕양구 청초로 10, A1-418호
- Google 지도 임베드(무료, API 키 불필요) — 해당 주소에 마커 표시
- 지도 아래(또는 옆) 정보 블록: 회사명, 주소, 전화/문의 링크
- 버튼 2개: "Google 지도에서 보기", "길찾기" — 새 창으로 Google Maps 열기
- 한국어/영어 전환(useLang) 지원: 섹션 제목·라벨·주소 표기

## 디자인
- 기존 프리미엄 톤 유지: 네이비/골드 팔레트, 라운드 코너, 부드러운 테두리와 그림자
- 지도는 16:9(모바일은 더 높은 비율)로 반응형, `Reveal` 페이드업 애니메이션 적용
- 지도 iframe은 `loading="lazy"`로 처리해 초기 로딩 속도 유지

## 배치
- 모든 페이지 공통 푸터 위에 노출되도록 루트 레이아웃의 푸터 직전에 배치할지, 홈과 문의하기 페이지에만 넣을지 선택이 필요합니다 → 기본은 **모든 페이지 푸터 위 공통 노출**로 진행합니다.

## 기술 메모
- 새 컴포넌트 `src/components/site/LocationMap.tsx`
- `https://www.google.com/maps?q=<인코딩된 주소>&output=embed` iframe 사용 (API 키·커넥터 불필요)
- `title` 속성과 접근성 라벨 추가, 외부 링크는 `rel="noopener noreferrer"`
- `src/routes/__root.tsx`에서 `<Footer />` 위에 렌더링
