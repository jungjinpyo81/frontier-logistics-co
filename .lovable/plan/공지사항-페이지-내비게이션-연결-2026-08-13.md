# 공지사항 페이지 내비게이션 연결

## 무엇이 문제인가

공지사항 페이지는 지구글로벌 사이트와 정상적으로 연동되어 있습니다. 다만 상단 내비게이션 바가 "투명 오버레이" 모드로 동작합니다. 다른 페이지는 상단에 어두운 히어로 이미지가 있어 흰 글씨 메뉴가 잘 보이지만, 공지사항 목록/상세 페이지는 배경이 밝아서 흰 글씨 메뉴가 보이지 않습니다. 그래서 상위 메뉴로 갈 방법이 없는 것처럼 보입니다. (스크롤을 조금 내리면 메뉴가 나타납니다.)

## 수정 내용

1. 밝은 배경 페이지에서는 상단 메뉴를 처음부터 진한 네이비 배경으로 고정 표시
   - 공지사항 목록 `/notices`, 공지사항 상세 `/notices/:id` 등 히어로가 없는 페이지에 적용
   - 스크롤 여부와 무관하게 메뉴가 항상 또렷하게 보임
   - 메뉴가 콘텐츠를 가리지 않도록 상단 여백 유지

2. 공지사항 목록 페이지에 위치 표시(브레드크럼) 추가
   - `홈 > 문의 / 공지 > 공지사항` 형태, 각 항목 클릭 시 이동

3. 공지사항 상세 페이지의 이동 버튼 보완
   - 기존 "목록으로" 버튼 유지 + 브레드크럼 추가
   - 이전 페이지로 돌아가는 동작도 자연스럽게 처리

## 기술 메모

- `src/routes/__root.tsx`에서 `<Navbar overlay />`를 현재 경로 기준으로 판단하도록 변경(히어로가 있는 페이지만 overlay).
- `src/components/site/Navbar.tsx`의 `solid` 계산 로직은 그대로 활용.
- 브레드크럼은 `@tanstack/react-router`의 `Link`를 사용하는 작은 공용 컴포넌트로 추가하고 두 공지 페이지에서 재사용.
- 텍스트는 한국어/영어 모두 `useLang` 기준으로 처리.
