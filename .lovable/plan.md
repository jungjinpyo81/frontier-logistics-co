# 상단 메뉴 호버 드롭다운 하위 메뉴 추가

## 목표
상단 네비게이션 메뉴에 마우스를 올리면(hover) 해당 메뉴의 하위 메뉴가 드롭다운으로 나타나도록 구현합니다.

## 하위 메뉴 구조

각 메뉴의 기존 페이지 섹션을 기반으로 하위 메뉴를 구성합니다. 하위 메뉴 항목을 클릭하면 해당 페이지의 해당 섹션으로 스크롤됩니다.

| 메뉴 | 하위 메뉴 (한국어 / English) |
|------|------------------------------|
| 회사소개 | 연혁 / 철학 / 가치 / 비전 |
| 서비스 | 해상 운송 / 항공 운송 / 국제특송 / 내륙 운송 / 보관·풀필먼트 / 특수화물 |
| 글로벌 네트워크 | 아시아 태평양 / 유럽 / 중동 / 아프리카 / 북미 / 중남미 |
| 무역 솔루션 | (하위 메뉴 없음 — 단일 페이지) |
| 인사이트 | (하위 메뉴 없음) |
| 문의하기 | (하위 메뉴 없음) |

## 구현 방식

### 1. Navbar.tsx 수정 (`src/components/site/Navbar.tsx`)
- `NAV` 배열에 각 메뉴의 `children` 하위 메뉴 데이터 추가 (라벨 + 해시 ID)
- React state(`hoveredMenu`)로 hover 중인 메뉴 추적 (`onMouseEnter` / `onMouseLeave`)
- 각 메뉴 항목 아래에 드롭다운 패널 렌더링:
  - 메뉴와 패널 사이 간격을 메뉴 li 영역으로 커버하여 마우스 이동 시 드롭다운이 유지되도록 설계
  - 디자인: 흰색 배경 / 네비 골드 액센트 / 기존 디자인 시스템(네이비 텍스트, 골드 호버) 유지
  - 투명(오버레이) 상태에서는 다크 배경, 솔리드 상태에서는 화이트 배경 사용
- 모바일에서는 기존 가로 스크롤 메뉴 유지 (드롭다운은 데스크톱 hover 전용, `md:` 이상에서만 노출)

### 2. 각 페이지에 섹션 ID 추가
하위 메뉴 해시 링크(`/our-story#history` 등)로 스크롤 이동이 가능하도록 각 페이지의 섹션에 `id` 속성을 추가합니다.

- **`src/routes/our-story.tsx`**: 연혁 섹션 `id="history"`, 철학 `id="philosophy"`, 가치 `id="values"`, 비전 `id="vision"`
- **`src/routes/services.tsx`**: 해상 `id="ocean"`, 항공 `id="air"`, 특송 `id="express"`, 내륙 `id="inland"`, 보관 `id="warehousing"`, 특수화물 `id="special"`
- **`src/routes/global-network.tsx`**: 각 리전 버튼에 데이터 속성 매핑 (해시 클릭 시 해당 리전 자동 선택)

### 3. 해시 스크롤 동작
- TanStack Router의 `<Link to="/services#ocean" />` 형태로 해시 전달
- 페이지 로드 후 해시가 있으면 해당 섹션으로 `scrollIntoView` (각 페이지 컴포넌트에 `useEffect` 추가)
- 글로벌 네트워크의 경우 해시값을 읽어 `setRegion`으로 리전을 자동 변경

## 기술 고려사항
- 드롭다운 패널에 약간의 페이드/슬라이드 인 애니메이션 적용 (기존 `fade-up` 톤과 일관성 유지)
- `onMouseLeave`는 메뉴 항목 + 드롭다운 패널 전체를 감싸는 컨테이너에 적용
- 접근성: `aria-haspopup`, `aria-expanded` 속성 추가
- 모바일(`md:` 미만)에서는 드롭다운 숨김, 기존 가로 스크롤 메뉴 유지
