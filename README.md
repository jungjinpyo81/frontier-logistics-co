# Global Connect Hub

PROJECT: 지구글로벌 공식 홈페이지 제작

프로젝트 개요

대한민국의 글로벌 물류·포워딩 기업인 "지구글로벌"의 공식 홈페이지를 제작한다.

전통적인 포워딩 회사 홈페이지가 아니라, 글로벌 비즈니스 파트너이자 현대적인 브랜드 기업으로 보이도록 디자인한다.

Armored Fresh의 브랜드 감성과 스토리텔링, Flexport의 현대적인 UX, 글로벌 물류기업의 신뢰성을 결합한 방향으로 설계한다.

브랜드 철학

우리는 단순히 화물을 운송하지 않는다.

사람과 비즈니스, 그리고 세계를 연결한다.

지구글로벌은 글로벌 공급망과 물류 네트워크를 통해 고객의 성장을 지원하는 파트너가 되고자 한다.
